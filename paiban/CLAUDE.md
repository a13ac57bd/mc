# 排班系統

公司內部排班網頁：員工填寫下下週 7×24 小時的可上班時段，管理員手動排班並公布，員工查看下週班表。
**完整背景、需求決定、資料模型、API、測試步驟與待辦事項都在 [`HANDOFF.md`](HANDOFF.md)，開始工作前先讀它。**

## 規則
- 使用者說繁體中文（台灣），回覆、介面文字、註解都用繁體中文
- 只用 Python 標準函式庫，不要引入需要 `pip install` 的套件；前端不用框架、不要建置步驟
- 部署環境是一台共用的 Windows 電腦，只在本機使用（伺服器綁 `127.0.0.1`）。不要做需要付費的服務
- 時段格式：每天一個 24 位元整數（bit h = h:00～h+1:00），`week_start` 是週一的 `YYYY-MM-DD`
- 改了功能要同步更新 `README.md`（給使用者）和 `HANDOFF.md`（給開發者）

## 執行
```
python server.py --open                 # http://127.0.0.1:8080
set PAIBAN_DB=C:\temp\test.db           # 測試時用另一個資料庫，不要動到正式的 paiban.db
```
