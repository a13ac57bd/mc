# 排班系統

員工在**公司這台電腦**上填寫「下下週」每天 24 小時中願意上班的時段，查看「下週」的班表；管理員排班、公布。

- 只用 Python 內建功能，**不需要安裝任何套件**
- 資料全部存在 `paiban.db` 一個檔案裡（SQLite）
- 只有這台電腦能使用，網路上的其他裝置連不進來，也不用設定防火牆

## 規則

| 項目 | 說明 |
|---|---|
| 登入 | 員工編號＋密碼。**第一次登入輸入的密碼會成為之後的密碼**（至少 4 個字） |
| 預設帳號 | `001`～`100`（員工）、`admin`（管理員）。第一次啟動後，**請馬上用 `admin` 登入設定管理員密碼** |
| 填寫 | 永遠是「下下週」（週一到週日）。截止時間是本週日 23:59，週一 00:00 起自動換成下一週，上一週就鎖定了 |
| 查看 | 員工可以看本週和下週的班表，但要管理員按「公布」後才看得到 |
| 忘記密碼 | 管理員在「員工管理」按「重設密碼」，員工下次登入輸入的密碼就是新密碼 |
| 共用電腦 | 關掉瀏覽器就登出；沒操作會自動登出（員工 2 分鐘、管理員 30 分鐘，最後 30 秒會倒數提醒，**未儲存的修改會遺失**）；瀏覽器不會記住密碼 |
| 停用員工 | 停用後無法登入，也不會出現在排班表；資料會保留 |

## 管理員排班流程

1. 「排班」頁預設顯示**下週**，用 ◀ ▶ 切換週次（下下週可以看員工填寫的即時狀況）
2. 選星期幾，淺綠色是員工可以上的時段；點格子（或按住滑鼠拖曳）排班，變藍色
3. 紅色＝排了但員工沒有填可上的時段（提醒用，仍然可以排）
4. 最下面一列是每小時排了幾個人；右邊是每個人當天和本週的時數
5. 「儲存草稿」員工看不到；「儲存並公布」後員工才看得到。公布後還可以修改再更新

## 安裝（公司 Windows 電腦）

1. 到 <https://www.python.org/downloads/> 下載 Python 3，安裝時**勾選「Add python.exe to PATH」**
2. 把整個 `paiban` 資料夾複製到電腦上，例如 `C:\paiban`
3. 雙擊 `start.bat`，會跳出一個黑色視窗（伺服器，**不要關掉**），並自動打開瀏覽器
4. 先用 `admin` 登入設定管理員密碼
5. 之後員工直接在這台電腦的瀏覽器打開 <http://127.0.0.1:8080> 填寫（建議加入書籤或放在桌面）

### 開機自動啟動
1. 按 `Win + R`，輸入 `shell:startup`，按 Enter
2. 在打開的資料夾裡，按右鍵 →「新增」→「捷徑」，目標選 `C:\paiban\start.bat`

（電腦要設定成不會自動睡眠：設定 → 系統 → 電源 → 螢幕與睡眠 → 睡眠設為「永不」）

### 備份
- 雙擊 `backup.bat`，會在 `backups\` 資料夾產生一份備份（伺服器開著也可以執行），只保留最近 60 份
- 自動每天備份：打開「工作排程器」→「建立基本工作」→ 每天 → 啟動程式選 `C:\paiban\backup.bat`
- 建議偶爾把 `backups\` 複製到別的地方（USB、雲端硬碟），避免電腦壞掉時資料一起遺失
- 還原：關掉伺服器，把備份檔複製回來並改名成 `paiban.db`

## 之後想開放手機連線

把 `start.bat` 裡的 `server.py --open` 改成 `server.py --open --host 0.0.0.0`，其他裝置就能用 `http://這台電腦的IP:8080` 連線（還要設定 Windows 網路為「私人」並允許防火牆）。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `server.py` | 伺服器（API＋網頁） |
| `static/` | 網頁畫面 |
| `start.bat` | 啟動伺服器 |
| `backup.py` / `backup.bat` | 備份資料庫 |
| `paiban.db` | 資料庫（第一次啟動時自動建立，不放進 git） |
